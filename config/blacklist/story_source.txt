# Cada línea es un REGEX de Python, sin distinguir mayúsculas. Se contrasta contra
# el TÍTULO y el @username del canal del que viene la historia, que es lo único
# que la Bot API entrega siempre (el contenido solo se lee por Telethon, y solo
# durante las 24 h que vive la historia).
#
# Esta lista NO decide sola. Solo pesa cuando alguien comparte la historia de otro
# canal y apenas ha escrito en el grupo; a un usuario asentado el trust score lo
# protege. Aun así, ponlo difícil: aquí NO van palabras corrientes. «Ofertas» o
# «Noticias» banearían canales legítimos.
#
# IMPORTANTE: pon SIEMPRE \b alrededor. Sin límites de palabra, «rich» casa dentro
# de «Zürich» y «pump» dentro de «Pumpkin»: banearías canales legítimos.
#
# Puedes añadir los tuyos en config/blacklist/custom/ (no se pierden al actualizar)
# o desde el panel /config.
